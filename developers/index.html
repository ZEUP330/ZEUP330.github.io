      为什么没有地图

      你要的是「房企在各城市的项目点 + 暴雷点 + 区县均价分布」。我按权威来源逐个查过，卡在这几处：

      • 项目点位：没有免费的机器可读数据集。上市公司年报只披露到「进入 X 个城市」这种粒度，项目级坐标只存在于贝壳、安居客这类商业平台，要爬且受其服务条款限制。
      • 区县级均价：统计局只发布 70 城价格指数（不是价格）。区县级成交均价在各市住建委/房管局手里 —— 北京住建委是项目级、要自行按区聚合，深圳房地产信息平台又是另一套页面。几十个城市各一套 HTML、无 API、对境外 IP 不友好，而这个站的更新是跑在 GitHub 的美国 runner 上。
      • 违约名单：交易所没有统一的「违约债券名单」下载入口。上证债券信息网和深交所债券公告是逐条公告，需要按发行人检索；全国法院破产重整案件信息网是门户页面不是接口。实务上要靠公告 + 评级机构报告 + 商业数据库交叉验证，做不成每日自动更新。

      所以这一页退回到能站住的那部分：交易所价格。它不能告诉你某个楼盘停没停工，但能准确告诉你市场在哪一天给这家公司判了刑，而且明天还会自动更新。

      数据与口径

      • 收盘价来自 Yahoo Finance 公开 chart 接口，港股与 A 股均取 2015 年起的日频
      • 回撤基准是各公司自身 2015 年以来的最高收盘，不是行业指数，也未做汇率换算（港股为港元、A 股为人民币，回撤是比例所以不受影响）
      • 未复权价格会被分红和拆并股影响；对跌幅 90% 以上的公司，这点误差不改变结论
      • 「停牌/退市」由行情停止更新超过 45 天判定，不是交易所公告口径
      • 所有制标签依据公司公开股权结构人工标注
      • developers.json — 原始派生数据
      股价是市场定价，不是对企业经营状况的判断，也不构成任何投资建议。已停牌或退市公司的最后价格不代表其资产的清算价值。
