两翼高、中间低就是「微笑」；左高右低是「偏斜」，说明市场为下跌保护付的溢价更高。

数据与口径

  • Deribit API 文档 — 用的是 public/get_book_summary_by_currency 与 public/get_index_price，公开只读，无需鉴权
  • IV 取交易所的 mark_iv（标记波动率），不是自己反解 BS 得来的
  • 曲面按 OTM 惯例取值：行权价低于远期价用看跌一侧，高于则用看涨一侧，再按 行权价／远期价 插值到统一网格
  • options.json · history.json — 原始快照，直接可下载
行情为快照，非实时，仅作数据可视化演示，不构成任何投资建议。加密期权波动极大，别拿这页面做交易决策。
