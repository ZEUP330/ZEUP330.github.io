# notes/

页面上的事实核对记录。站里的金融与政策数字都要能追到官方来源并标注核对日期
（见根目录 `CLAUDE.md` 的「数据与口径」），这个目录存的就是每次核对的过程与出处。

命名：`YYYY-MM-DD-facts-<范围>.md`，一次核对一个文件，不覆盖旧的 —— 旧文件本身
就是「这个数字在那天是什么样」的证据。

每份文件里一页一节，节内一张表：

| 页面位置 | 页面当前值 | 核对结果 | 正确值 | 一手来源 | 来源日期 |
|---|---|---|---|---|---|

核对结果只有四种：仍成立 / 已过时 / 错误 / 未能核到一手源。最后一种照写，不要
用二手报道或记忆里的数字填上去。
